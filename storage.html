Physical Storage Layers

Linux organizes storage from the raw hardware up to the user directory:

  • Physical Disk: The hardware device (e.g., `/dev/sda`).
  • Partition: Fixed logic divisions (e.g., `/dev/sda1`).
  • Filesystem: The structure used to store data (e.g., `ext4`, `XFS`).
  • Mount Point: The directory used to access the data (e.g., `/var`).
Why this matters: Proper partitioning prevents a single directory (like logs) from filling the whole disk and crashing the system.

Logical Volume Management

LVM adds a layer of abstraction that allows for flexible resizing without downtime.

The LVM Three-Tier System:

  • Physical Volume (PV): Disks initialized for LVM.
  • Volume Group (VG): A pool combined from one or more PVs.
  • Logical Volume (LV): "Virtual partitions" carved from the VG.
Why this matters: If your database runs out of space, you can add a new physical disk and expand the Logical Volume instantly.

RAID Fundamentals

RAID 0 (Striping): Performance focus. No redundancy. If 1 disk fails, all data is lost.

RAID 1 (Mirroring): High reliability. Data is duplicated. 50% capacity efficiency.

RAID 5 (Parity): Balanced. Requires 3+ disks. Can survive 1 disk failure.

LVM vs RAID: RAID provides reliability (hardware protection). LVM provides flexibility (space management). Often, admins use both!
