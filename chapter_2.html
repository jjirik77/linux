Mastering Linux Text Editors: vi/vim and nano

Master text file creation and modification on headless Linux servers. Learn nano's beginner-friendly shortcut interface and vim's powerful modal editing paradigm, modes, and command keystrokes essential for certification and system administration.

Nano Text Editor

A modeless, user-friendly editor featuring bottom-screen shortcut reminders. Ideal for quick configuration edits using control key combinations like Ctrl+O (writeout) and Ctrl+X (exit).

Vim Modal Editing

Master vim's distinct modes: Command Mode (for navigation and shortcuts), Insert Mode (for typing text), and Ex/Last Line Mode (for saving and quitting with :wq).

Exam Keybindings & Tips

Text Editors Command Quick Reference (vi/vim vs nano)

Operation GNU nano Shortcut Vim Keystroke (Command Mode)
Enter Insert Mode / Type Direct typing (modeless) i (insert before cursor), a (append after)
Return to Command Mode N/A (modeless) Esc
Save File (Write) Ctrl + O (WriteOut) :w
Exit Editor Ctrl + X :q (or :wq to save and exit)
Search Text Ctrl + W (Where Is) /search_term (n for next)
Delete Current Line Ctrl + K (Cut text) dd
Paste Cut/Copied Line Ctrl + U (Uncut text) p

GNU nano Practice Lab

Step-by-Step Exercise Checklist

1. Open a file:
nano config.txt

Launches nano editor for the specified file.

2. Type content (Insert Text):

Type directly using keyboard: SERVER_NAME=web01. Use arrow keys to navigate.

3. Save changes:
Ctrl + O

Writes out changes (Press Enter to confirm filename).

4. Exit editor:
Ctrl + X

Returns to the bash prompt.

Vim Modal Practice Lab

Step-by-Step Exercise Checklist

1. Open file:
vim practice.txt

Opens file in Normal Mode with pre-loaded lines.

2. Insert Mode & Typing Text:
Press 'i' then type text

Insert text: Maintenance Window Scheduled. Press Esc to return to Normal Mode.

3. Navigation & Movement:
h (left), j (down), k (up), l (right)

In Normal mode, move the cursor over specific characters and words in your text.

4. Delete & Yank Text:
dd (delete line) / yy (yank line)

Position cursor on target line, type dd to delete or yy to copy, then press p to paste.

5. Search String:
/Chapter 2

Type /Chapter 2 and press Enter to instantly locate and jump to that string in the text.

6. Save & Quit:
:wq

Type colon, wq, and press Enter to save file changes and exit back to bash.
