Mastering the Mode

In Linux, everything is a file. Controlling who can read, write, and execute these files is the foundation of system security.

Permission Groups

User

The Individual Owner

The person who created the file or was assigned ownership via chown.

Group

The Department/Team

A set of users defined in the system who share permissions for collaborative files.

Others

Everyone Else

Often called "world" permissions. Any user on the system who isn't the owner or in the group.

Special Permissions: SUID, SGID, and Sticky

SUID u+s

Allows a user to run an executable with the owner's privileges.

-rwsr-xr-x

SGID g+s

Files created in the directory inherit the group of the parent directory.

drwxr-wsr-x

Sticky Bit t

Used on directories to prevent users from deleting files owned by others.

drwxrwxr-wt
Pro Tip: If you see a capital S or T, it means the special bit is set but the underlying execute (x) bit is missing—this is usually an error or non-functional.
