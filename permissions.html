01. Learn

Permission Groups

Owner (u): The user who owns the file.
Group (g): Users in the file's group.
Others (o): Everyone else on system.

Each group has a set of rwx bits: Read (4), Write (2), and Execute (1).

# ls -l snapshot
-rwxr-xr--
rwx (7) : User Owner
r-x (5) : Group Owner
r-- (4) : Others (World)

SUID (u+s)

File runs with owner permissions. Shown as 's' in user slot.

SGID (g+s)

Inherits group of directory. Shown as 's' in group slot.

Sticky Bit (+t)

Only owner can delete files. Shown as 't' in others slot.

Examples: -rwsr-xr-x | drwxrwsr-x | drwxrwxrwt
