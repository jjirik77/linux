Managing Linux Files and Directories

Welcome to your interactive Linux environment. Understanding how to navigate and manage files via the Command Line Interface (CLI) is a fundamental skill for any Linux administrator.

Read through the concepts below and immediately practice the commands in the terminal on the right. This simulates a real Linux server environment.

📁 1. The Directory Hierarchy

Unlike Windows, which uses drive letters (like C:), Linux organizes all files and directories into a single unified tree structure. The absolute top of this tree is called the root directory, represented by a forward slash (/).

Important standard directories include:

  • /home: Contains personal directories for users (e.g., /home/student). When you log in, you start here.
  • /etc: Stores system-wide configuration files.
  • /var: Contains variable data, such as system log files.

🧭 2. Navigating the File System

Use these core commands to find out where you are and to move around:

  • pwd (Print Working Directory): Outputs the absolute path of your current location.
  • ls (List): Displays the files and directories inside your current location.
  • cd [path] (Change Directory): Moves your working directory to the specified path. Typing cd by itself returns you to your home directory.
Practice: Navigation 1. Type pwd to see your starting location.
2. Type ls to see what is in your home directory.
3. Type cd /etc to navigate to the configuration directory, then run ls again.
4. Type cd (with no arguments) to jump straight back home.

📝 3. Creating Files and Directories

As an administrator, you will constantly create organizational structures and configuration files:

  • mkdir [name] (Make Directory): Creates a new folder.
  • touch [name]: Creates an empty file. (If the file already exists, it updates its timestamp).
Practice: Creation 1. Ensure you are in your home directory (use cd).
2. Type mkdir Projects to create a folder.
3. Type cd Projects to move into it.
4. Type touch notes.txt to create an empty file.
5. Verify your work using ls.

🚚 4. Copying and Moving

Managing data often requires duplicating or relocating files:

  • cp [source] [destination] (Copy): Duplicates a file.
  • mv [source] [destination] (Move): Relocates a file. This command is also used to rename files if the destination is in the same folder.
Practice: Duplication & Renaming 1. While inside the Projects folder, type cp notes.txt backup.txt.
2. Rename the backup by typing mv backup.txt secret_notes.txt.
3. Use ls to see the results.

🗑️ 5. Removing Files and Directories

Keeping a system clean requires removing old data. Note: In Linux, there is no "Recycle Bin" by default. Deletions are permanent!

  • rm [file] (Remove): Deletes a file.
  • rmdir [directory]: Deletes an empty directory.
  • rm -r [directory]: Recursively deletes a directory and all of its contents. Use with extreme caution!
Practice: Deletion 1. Type rm secret_notes.txt to delete the file.
2. Go back up one directory by typing cd ..
3. Try to delete the folder: rmdir Projects. It will fail because notes.txt is still inside.
4. Force delete it by typing rm -r Projects.
