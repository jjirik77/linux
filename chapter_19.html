Scenario Analysis: The FRMS/SGMF Merger

Context: FRMS Corp recently merged with SGMF Inc. You are attempting to ssh into a legacy SGMF web server (`sgmf-web01`) but the connection times out. You ping the server, and it responds. Yesterday, network engineers migrated the firewall to a new subnet.

Step 1: Identify the problem
Action: Gather details. You know SSH times out, but Ping works. You might run `ssh -v user@sgmf-web01` to get verbose output.
Step 2: Determine recent changes
Action: Acknowledge the firewall migration that happened yesterday. This is a massive clue!
Step 3: Create a causal theory
Action: Theory: The new firewall rules allow ICMP (ping) but are blocking port 22 (SSH) to the SGMF subnet.

Memory & OOM Killer Simulation

When physical RAM is exhausted, Linux uses Swap. If Swap fills, the Out-Of-Memory (OOM) Killer terminates processes to save the kernel.

vmstat columnsVirtual Memory Statistics: Watch `swpd` (swap used), `si` (swap in), and `so` (swap out). High `si`/`so` indicates thrashing.

Storage & File Systems

I/O Schedulers

Modern SSDs and NVMe drives bypass legacy schedulers via multiqueue (blk-mq).

  • none: Ideal for fast NVMe (no scheduling overhead).
  • mq-deadline: Good for standard SATA SSDs.
  • bfq: Good for slow spinning HDDs (high latency).
Check scheduler: `cat /sys/block/sda/queue/scheduler`

Inode Exhaustion

A drive can have free space but fail to create files if it runs out of inodes (metadata structures).

$ df -i /var
Filesystem Inodes IUsed IFree IUse% Mounted on
/dev/sda2 1200000 1200000 0 100% /var

Fix: Delete millions of small temporary files.
