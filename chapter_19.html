The 7-Step Operational Framework

Review and verify the correct sequence of enterprise troubleshooting steps.

Workflow Sequence

1. Identify the problem
2. Establish recent changes
3. Create a theory of probable cause
4. Test theory to determine cause
5. Establish plan of action and implement fix
6. Verify full system functionality
7. Document findings, actions, and outcomes

Lab Exercise 19-1: Swap Allocation & Activation

Perform the sequence below to provision a 1GB swap block file and enable kernel virtual memory paging.

Step 1: Allocate zero-filled block

dd if=/dev/zero of=/swapfile bs=1M count=1024

Step 2: Restrict permissions

chmod 600 /swapfile

Step 3: Format swap structure

mkswap /swapfile

Step 4: Enable swap memory

swapon /swapfile
