Welcome, SysAdmin

Software management is the cornerstone of Linux administration. In this interactive lab, you will master the tools and workflows used to install, update, and troubleshoot applications on Enterprise Linux and Debian systems.

Lab Objective: Prepare for CompTIA Linux+ style tasks involving RPM, DNF, APT, and source compilation.

What we'll cover:

  • Dependency resolution and package foundations.
  • RPM and DNF (Red Hat family).
  • dpkg and APT (Debian family).
  • Universal formats (Snap, Flatpak).
  • Compiling from source and shared libraries.

Command Cheat Sheet

RPM (Local)

  • -i: Install
  • -U: Upgrade (Installs if missing)
  • -F: Freshen (Only upgrades existing)
  • -e: Erase (Uninstall)
  • -V: Verify integrity
  • -qi: Query information

DNF / APT (Repo)

  • dnf install [pkg]
  • dnf search [string]
  • apt update (refresh lists)
  • apt install [pkg]
  • apt upgrade (apply updates)

Shared Libraries

  • ldd [path]: List dependencies
  • ldconfig: Update library cache

Source Build

  1. tar -xvf [file]
  2. ./configure
  3. make
  4. make install
