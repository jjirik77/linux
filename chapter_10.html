CompTIA Linux+ Chapter 10 Command Reference

Essential package managers, shared libraries, and build tools

RPM (Low-Level Red Hat)

  • rpm -i pkg.rpm : Install package
  • rpm -U pkg.rpm : Upgrade or install fresh
  • rpm -F pkg.rpm : Freshen (upgrade only if exists)
  • rpm -e pkg : Erase / Remove package
  • rpm -qa : Query all installed packages
  • rpm -qi pkg : Query package info / description
  • rpm -ql pkg : Query files installed by package
  • rpm -qc pkg : Query config files for package
  • rpm -qf /path : Query package that owns file
  • rpm -qR pkg : Query required dependencies
  • rpm -V pkg : Verify integrity against RPM database

DNF / YUM / Zypper (Repo-Aware)

  • dnf install pkg : Resolve deps & install
  • dnf provides /path : Identify package owning file
  • dnf repolist : View enabled repositories
  • dnf check-update : Check available updates
  • dnf clean all : Purge local cache files
  • dnf localinstall file.rpm : Install local RPM with repo deps
  • zypper in pkg : openSUSE install package
  • zypper lr : List configured repositories

Debian dpkg & APT (Ubuntu / Debian)

  • dpkg -i pkg.deb : Install local deb package
  • dpkg -r pkg : Remove package (leaves config)
  • dpkg -P pkg : Purge package AND config files
  • dpkg -l : List installed packages
  • dpkg -L pkg : List files installed by package
  • dpkg -S /path : Find which package owns file
  • apt update : Refresh repo package index
  • apt upgrade : Upgrade all upgradable packages
  • apt-cache search str : Search repository cache

Source Builds & Shared Libraries

  • tar -zxvf src.tar.gz : Decompress source archive
  • ./configure --prefix=/usr : Check deps, make Makefile
  • make : Compile source code into binaries
  • sudo make install : Copy binaries to system path
  • ldd /bin/ls : List dynamic library dependencies
  • ldconfig : Update shared library cache
  • ldconfig -p : Print all cached libraries
  • LD_LIBRARY_PATH : Env var for custom library paths

RPM Verification Output Codes (CompTIA Favorite)

S : File Size differs
M : File Permissions / Mode differs
5 : MD5 / SHA checksum differs
D : Device major/minor mismatch
L : Symlink readlink mismatch
U : User ownership differs
G : Group ownership differs
T : Modification Time (mtime) differs
